# Package integration

Use the **installed version** for exact exports, types, token values, and examples. Install the `v0.3.0` GitHub tag with `npm install github:hyeonse-swing/hyeonse-design-system#v0.3.0`. This version includes the primitive components and expanded tokens; `v0.2.0` does not. For local development, run `npm run verify && npm pack` in this repository and install the resulting tarball in a consumer app.

Run `npm exec --no -- hds list`, `hds show <export-name>`, `hds tokens [name]`, `hds search <words>`, or `hds example <id>` in a consumer project; here use `npm run hds -- ...`. Search includes states, conditions, and token values. Each command accepts `--json`. The schema remains version 1. The public `./catalog.json` and `./catalog.schema.json` exports and package-root `llms.txt` / `llms-full.txt` offer file lookup. `entry.props` lists component-declared props only; `hds show` type context or the public `.d.ts` contains inherited native DOM attributes and refs.

Import `./tokens.css` and `./components.css` once. They provide semantic tokens and packaged control classes without a global reset. `./preferences` and `./react` retain the existing settings API. v0.3.0 adds `./primitives`: named `Button`, `TextField`, `Checkbox`, `Badge` functions and their Props types. Native attributes and React 19 refs pass through. There is no generic `Input`, `Card`, `Dialog`, or `Select` export. See [component usage](../../../docs/components.md) for states and accessibility.

`./preferences` exports `preferencesKey`, `defaultPreferences`, validation/parse/serialize helpers, `resolvedTheme`, `effectiveMotion`, `createPreferenceScript(storageKey?, defaults?)`, and `preferenceScript`. The default key is `hyeonse-site-preferences`. `Preferences` has `theme`, `accent`, `density`, `corners`, and `motion`; defaults are `system`, `cobalt`, `comfortable`, `crisp`, `full`. Put the initial script in the document head before CSS paints. Valid saved choices take priority over site defaults. System reduced motion takes priority over the saved motion preference.

`./react` exports `PreferencesProvider`, `usePreferences`, `ThemeToggle`, and `PreferencesPanel`. The Provider accepts `storageKey?`, `eventName?` (default `hyeonse:preferences`), and `defaults?: Partial<Preferences>`; the hook gives `preferences`, `setPreference`, and `resetPreferences`. The controls accept `locale='ko'|'en'`. Match a custom script storage key and defaults with the Provider. Inspect the target framework's document-head and client-component integration before applying the example.
