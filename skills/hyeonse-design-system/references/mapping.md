# Token mapping

Inventory the requested file, screen, or diff. For each hardcoded style, record its element, purpose, current value, candidate role token, and whether replacement preserves contrast and meaning. `--accent-solid` is for filled emphasis; `--accent-text` is for readable text, borders, and focus on ordinary surfaces. `--surface` groups content; `--surface-raised` separates a foreground card. A similar hex value alone does not justify a mapping.

For a read-only audit, report candidates and uncertain cases without editing. For an authorized migration, change only the agreed scope and check the actual render across supported settings. Propose a new token only for a recurring semantic role that current tokens cannot express.

For CSS enforcement in a consumer app, use the `hds-audit <consumer-root> [config-relative-path]` CLI when available. Keep exceptions file-specific with a stated reason and expected count. Its CSS-only scope does not prove that script or 3D colors conform.
