# 통합 검증 · 2026-10-08

포트폴리오에 공통 패키지를 적용하기 전후의 로컬 정적 빌드를 비교했다.

- Chrome: 9개 경로 × 390·1280px × 밝게·어둡게, 총 36개 화면. 기존 역할 토큰 값과 제목·설정 요소의 배치·글꼴·색 측정값이 같았다.
- 홈·작업실 8개 캡처는 pixelmatch threshold 0.1에서 차이 0픽셀이었다.
- 설정 변경, 새로고침 복원, 다른 탭 동기화, 기기 테마 변경, 기기 움직임 감소 우선, 초기화, 라디오 방향키 조작, 저장소 차단 시 조작, JavaScript 없는 다크 화면을 확인했다.
- 설정 패널 axe WCAG 2 A/AA 검사에서 위반이 없었다. 전체 사이트의 접근성 인증을 뜻하지 않는다.
- 견본 페이지는 390·1280px의 밝게·어둡게에서 가로 넘침과 JavaScript 오류가 없었다.
- 포트폴리오 TypeScript, 정적 빌드, 콘텐츠 검사(15페이지·210개 로컬 링크), CSS 토큰 검사를 통과했다.
- CSS 검사에 원시 색상과 공유 토큰 재정의를 심어 실패하는지 확인했다. 패키지 테스트는 잘못된 저장값, 초기 스크립트, 사용자 정의 키 이스케이프, SSR 의미 구조, 복수 패널의 ID·라디오 이름 분리를 포함한다.

기존 데스크톱 홈 배지 영역의 scrollWidth 초과는 전후에 동일하게 관찰됐다. 이번 분리 작업에서 변경하지 않았다. 실제 모바일 기기, 다른 브라우저, 프로덕션 배포는 위 로컬 검증 범위에 포함하지 않는다.
